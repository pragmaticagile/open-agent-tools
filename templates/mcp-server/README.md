# MCP Server Template

Use this folder as a checklist when adding a new MCP server.

Recommended files:

```text
README.md
LICENSE
.env.example
package.json
src/
```

README sections to include:

- What this MCP does
- Prerequisites
- Setup
- MCP client configuration
- Example prompts
- Troubleshooting
- Security
- Developer notes

Keep examples generic and use placeholders only.
